# reset-discord-channel
This repo includes a Discord bot that cleans up a Discord channel from messages.

You need to host the Discord bot of course somewhere (or download and run it locally).

- Run `!clear` inside a Discord channel to clear all channel's post (deletes all posts 1 by 1)
- Run `!clear X` inside a Discord channel to delete the last `X` posts inside the channel
  - For example, to delete 4 posts run `!clear 4`
